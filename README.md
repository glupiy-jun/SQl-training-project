# SQL Sales Analysis Project
A comprehensive SQL project to analyze e-commerce sales data using advanced business intelligence techniques.

## Features
- Complete database structure for online store
- Sample data for realistic analysis  
- Business KPI calculations
- Customer and product performance analytics
- Monthly sales trends and reporting

## Code structure 
The program is composed of six main components:
- **create_database.sql**: creates the database and all necessary tables
- **insert_data.sql**: populates tables with sample sales data
- **basic_analysis.sql**: calculates key business metrics and KPIs
- **monthly_revenue.sql**: analyzes revenue trends by month
- **top5_products.sql**: identifies top 5 products by revenue
- **category_sales_performance.sql**: analyzes sales performance by product categories
